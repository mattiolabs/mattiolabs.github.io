# andreamatt81.github.io

Pagina profilo personale pubblicata con GitHub Pages.

## Come modificarla

Tutto il contenuto è nel file `index.html`. Apri il file su GitHub, clicca sull'icona
della matita ✏️ e cambia i testi segnalati dai commenti:

- **Intestazione**: nome, ruolo e link (GitHub, LinkedIn, email)
- **Chi sono**: una breve presentazione
- **Competenze**: una voce `<li>` per ogni competenza
- **Progetti**: un blocco `<a class="project">` per ogni progetto

Salva con "Commit changes": dopo un minuto circa la pagina online si aggiorna.
